# Solidity Contracts

[ZkApiVault](../../contracts/src/ZkApiVault.sol) accepts native ETH deposits in
whole gwei, maintains the depth-32 active-note tree, and pins the server's state
and clearance signing keys. Amounts are bounded by `2^53 - 1` gwei.

[NoteLeafLib](../../contracts/src/libraries/NoteLeafLib.sol) and
[MerkleUpdateLib](../../contracts/src/libraries/MerkleUpdateLib.sol) use the
[BN254 Poseidon implementation](../../contracts/src/libraries/Bn254Poseidon.sol)
shared with the circuit parameters. That library is generated by
`scripts/generate-poseidon.mjs` from the parameters in
[the setup manifest](../../setup/v2/manifest.json) as a fully unrolled
permutation; the straightforward evaluation of the same parameters is kept in
[test/reference](../../contracts/test/reference/Bn254PoseidonReference.sol) and
the two are compared on random, edge-case and mainnet-fork inputs by
`forge test`.

[Groth16ProofAdapter](../../contracts/src/adapters/Groth16ProofAdapter.sol)
verifies the request and withdrawal statements directly. Public deployment
fields and pinned signing keys are checked by the vault before settlement.

Mutual close pays the final balance to the destination and the spent balance
to the treasury. Escape initiation immediately removes the active leaf. A
matching historical request proof can challenge a stale escape and restore the
leaf; otherwise the user finalizes after the deadline. Active expired notes can
be claimed for the treasury. [Types.sol](../../contracts/src/libraries/Types.sol)
defines the current note state and proof statements.
